# 设计方案：全站文集头版式结构重构（去 AI 味）

日期：2026-07-11
状态：已确认
范围：全站六页的结构与布局重排。保留全部内容与功能逻辑，视觉基调沿用 2026-07-11 复古风精致化成果（见 `2026-07-11-ui-retro-refinement-design.md`）。

## 背景与目标

站点当前结构是典型的「AI 生成站配方」：hero（标题+副标题+说明+统计框）+ 假代码窗口 + 均质卡片网格 + 居中下划线板块标题 + emoji 图标卡片。目标是把结构重排为**文集头版式**——像一本文集/报刊，靠版式编辑与字体层级支撑吸引力，去除模板指纹。

## 设计原则

1. **去卡片化**：内容直接排在纸面上，用留白、字号层级、细分隔线（规则线）组织；不再使用圆角盒子网格。
2. **版式编辑化**：非对称头版、大字号头条、目录式清单。
3. **删除装饰组件**：假代码窗口、统计框、居中下划线标题、emoji 大图标、feature 标签堆、渐变精选徽章。
4. **栏宽节奏**：全站以 720px 阅读栏为基准，首页头版区放宽至约 880px；「头版宽、正文窄」。

## 全局框架

### Header（重构为单行）
- 结构：小尺寸 Logo + 站名「数得其道」（文楷）+ 导航「文章 / 工具 / 项目 / 关于」+ 主题切换按钮。
- 删除「首页」导航项（点站名回首页）；RSS 链接移至 Footer；副标题「道 · 法 · 术 · 器」移至首页引言行。
- 激活态样式沿用上一轮（accent 色 + 2px 下划线）。主题切换 JS 逻辑与 setActiveNavLink 逻辑不动（导航项数据相应减少）。

### Footer（新增 `components/Footer.astro`）
- 单行式：「数得其道 © 年份 · RSS · GitHub」，小字、细上边线，全站统一挂载在 Layout。

### 搜索
- SearchBox 从首页移除，移至文章列表页顶部；组件与搜索 JS/API 逻辑原样保留。

## 页面设计

### 首页（文集头版）
- **引言行**：「道 · 法 · 术 · 器 —— 探索数字世界中的道法术器」小字一行（复用现有文案，不新造内容）。
- **头条**：最新的 featured 文章（无 featured 则取最新一篇）：大字号文楷标题（桌面约 2.5–3rem）、日期+标签 meta 小字、摘要 2–3 行、「继续阅读 →」链接；区块上下以细规则线框定；无图片、无卡片。
- **次条**：除头条外最新 2 篇，双栏简排（标题 + 一行摘要 + 日期）。
- **目录**：其余全部文章按月分组（小节标题如「七月」），每行「· 标题 ⋯⋯ 日期」；日期右对齐。全部列出，删除「查看所有文章」按钮。
- **删除**：hero 全套（标题/副标题/说明/统计框）、假代码窗口（AI_PROMPT.md）、首页搜索框、精选与最新两个卡片网格。

### 文章列表页 `/posts`
- 卡片网格 → **按年分组的目录清单**（复用 PostList 组件）。
- 搜索框置顶。
- 标签筛选保留功能，重样式为行内文字标签（如 `#系统思维 ×3`），点击筛选 JS 逻辑不动。

### 文章阅读页 `/posts/[slug]`
- 继承上一轮栏宽（720px）、行距、字号，只改三处：
  1. 去掉正文卡片包裹（`.article-content` 的背景色块、边框、圆角、阴影 → 正文直接排在纸面上）；
  2. 标题区与 meta 行由居中改为左对齐；
  3. 删除「⭐ 精选文章」渐变徽章。
- TOC 右侧浮动布局保留。

### 工具页 `/tools`
- emoji 图标卡片格 → **按分类分组的工具索引**：分类为小节标题，其下每行「工具名 — 一句话描述」文字链接；不再展示 features 标签堆与 emoji 大图标。
- 工具数据数组与各工具子页面不动。

### 项目页 `/projects`
- GitHub pinned 卡片格 → **项目清单**：每项「名称（外链）+ 描述 + 语言/星标小字 meta」，细分隔线分隔。
- GitHub GraphQL 抓取逻辑、语言色映射原样保留，只换渲染模板与样式。

### 关于页 `/about`
- 头像区块 + 格言引用框 + 内容块网格 → **单栏文章式**：顶部小头像 + 姓名/职衔一行（左对齐）；格言变为正文开头的普通 blockquote；其余文字按 720px 文章栏直排。全部文字内容原样保留。

## 响应式

- 移动端（≤768px）：头条字号降至约 1.75rem；次条双栏并为单栏；目录行标题与日期同行、日期右对齐，过长标题换行后日期不错位（flex + 不换行日期）；单行 Header 在窄屏收紧间距（四个导航项 + 主题切换可单行排下）。
- 全站无横向滚动。

## 不做的事

- 不改任何 Markdown 文章内容与站点文字性内容（自我介绍、关于页文字、工具描述均照搬）。
- 不动功能逻辑：搜索（fuse.js + /api/search.json）、主题切换、代码高亮与复制、GitHub 项目抓取、RSS、sitemap。
- 不改路由与 URL；不新增 npm 依赖。
- 不改配色、字体、纹理体系（沿用上一轮）。

## 验证方式

1. `npm run build` 通过。
2. 浏览器截图 QA：六页 × 明/暗两主题 × 桌面/移动（~390px）。
3. 核对点：头版层级（头条→次条→目录）清晰；目录行窄屏不错位；搜索/标签筛选/主题切换/项目抓取功能正常；无横向滚动；无 PostCard 残留引用。
